# عمران-بت

راهنمای امنیت و حریم خصوصی واتساپ

## قابلیت‌ها
- چک‌لیست امنیتی
- امتیاز امنیتی
- راهنمای حریم خصوصی
- راهنمای تأیید دومرحله‌ای
- بررسی لینک‌های مشکوک

## اجرا
`npm start`

## آزمایش
`npm test`

## نکته
این پروژه ابزار راهنما و بررسی اولیه است و مستقیماً به واتساپ دسترسی ندارد.
بررسی HTTPS به‌تنهایی امنیت سایت را تضمین نمی‌کند.
